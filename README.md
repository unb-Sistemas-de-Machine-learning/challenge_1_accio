## 🚀 Gerenciamento de Dependências com `uv`

Este projeto utiliza o [uv](https://docs.astral.sh/uv/) como gerenciador de dependências e ambiente Python.

### 📦 Pré-requisitos

Certifique-se de ter o `uv` instalado. Se ainda não tiver:

```bash
# Linux / macOS
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```
